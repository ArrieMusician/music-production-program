# music-production-program
Although there are a lot of music production software out there, I have a goal to merge various features from different platforms into one. Users of this software will be able to: 1) Write a song; 2) Record and mix the song; 3) Distribute the song; Identify the key/chords/bpm of an already existing song; 4) Identify a song name (mush like shazam).
